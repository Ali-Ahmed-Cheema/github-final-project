# Simple Interest Calculator

A simple Bash script designed to calculate simple interest given the principal amount, annual rate of interest, and time period.

## Usage
The script prompts for the following inputs:
- **Principal:** The initial amount of money.
- **Rate:** The annual interest rate (percentage).
- **Time:** The duration in years.

## Formula
$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
- $P$ = Principal amount
- $R$ = Rate of interest per annum
- $T$ = Time period in years
